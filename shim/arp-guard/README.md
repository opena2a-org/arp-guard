# arp-guard

This package was published as `arp-guard` up to 0.3.0. From 0.4.0 it is [`agent-runtime-protection`](https://www.npmjs.com/package/agent-runtime-protection). `arp-guard` 0.4.0 is a shim that re-exports that package, and it is deprecated. To move, install `agent-runtime-protection` in place of `arp-guard` and change the import specifier. Nothing else changes: at 0.4.0 both names export the same API.
